## 버그: CRM 탭 CSS 간헐적 깨짐 (큐·퍼널·기간 버튼)
## 원인:
- `_crm_styles_injected` 세션 플래그로 CSS를 1회만 주입 → Streamlit rerun 시 `<style>` DOM 제거됐는데 재주입 안 됨
- 기간 필터 `:has(.crm-period-anchor) + horizontalBlock` — toolbar markdown 때문에 **형제 선택자 불일치**
- 방문 0일 때 퍼널 전환율 200%+ 표시 → 레이아웃 깨진 것처럼 보임
## 영향 파일:
- `assets/crm.css` (신규)
- `utils/crm_styles.py` — 매 렌더 parent head 주입
- `utils/crm_ui.py` — st.radio 기간 · crm-root · rate cap
## 수정 내용:
- CSS 파일 분리 + `inject_crm_styles()` 매번 실행 + `#dgt-crm-styles` parent head 고정
- 기간: `st.columns(4)` → `st.radio(horizontal)` + `.crm-period-wrap`
- 퍼널 %: 0~100만 표시 (`_fmt_step_rate`)
## 재발 방지:
- `tests/test_crm.py` — crm.css · radio · no session gate
- `tests/test_crm_styles.py` — inject every render
## 검증 명령:
`python -m pytest tests/test_crm.py tests/test_crm_styles.py -q`
