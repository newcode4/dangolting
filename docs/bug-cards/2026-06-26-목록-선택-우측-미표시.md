## 버그: 목록에서 선택해도 우측 프로필이 바로 안 뜸
## 원인:
`@st.fragment`로 검색·목록을 감싸면서 `selected`를 fragment 바깥에서 한 번만 읽음.
fragment만 재실행될 때 선택 상태가 갱신되지 않아 우측 패널이 빈 채로 남음.
## 영향 파일:
- `app.py` (tab1 레이아웃, `toggle_select`)
## 수정 내용:
- `@st.fragment` 제거 → 선택 시 전체 rerun으로 좌·우 동시 갱신
- `toggle_select`에서 `selected` 리스트를 복사 후 session_state에 저장
## 재발 방지:
- `tests/test_selection.py` — 선택 토글 로직 단위 테스트
## 검증 명령:
`python -m pytest tests/test_selection.py -q`
