## 버그: 랜딩 푸터「관리자」클릭 무반응
## 원인:
- Streamlit `st.markdown`의 `<script>`는 실행되지 않아 postMessage 수신 브릿지가 부모에 등록되지 않음
- iframe 클릭 핸들러가 `preventDefault()`만 하고 실제 navigation이 발생하지 않음
- Streamlit `components.html` iframe sandbox는 `allow-top-navigation` 없음
## 영향 파일:
- `app.py` — `_inject_landing_parent_nav_bridge()`
- `utils/landing.py` — `.footer-link-admin` 클릭 핸들러
## 수정 내용:
- height=0 `components.html`로 부모 `document.head`에 `#dgt-nav-bridge` 스크립트 주입 (부모 컨텍스트에서 `location.assign`)
- 푸터 클릭: 브릿지 있으면 postMessage → 같은 탭 이동, 없으면 `window.open` fallback
## 재발 방지:
- `tests/test_landing.py` — admin 링크·dgt-navigate·bridgeReady 검사
- `tests/test_theme_css.py` — bridge 주입 함수·dgt-nav-bridge id 검사
## 검증 명령:
`python -m pytest tests/test_landing.py tests/test_theme_css.py -q`
