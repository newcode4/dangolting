## 버그: 모바일 CRM 데이터 한눈에 안 보임
## 원인:
- `theme.css`에서 CRM 기본 스타일(4열 grid)이 `@media (max-width:768px)` 규칙보다 **뒤에** 정의되어 모바일 grid가 무시됨
- `st.metric` + `st.columns`가 좁은 화면에서 세로로 길게 쌓여 가독성 저하
## 영향 파일:
- `utils/crm_ui.py`
- `assets/theme.css`
## 수정 내용:
- CRM 탭 진입 시 모바일 우선 `_CRM_STYLES` 주입 (`!important` + inline grid fallback)
- 핵심 지표 2×2, 전환 흐름 2×3, 알림 카드 가로형(숫자|설명)
- KPI/유입/환불을 HTML metric grid로 통일
- 퍼널 막대 `crm-bar-row` 그리드로 모바일 대응
## 재발 방지:
- `tests/test_crm.py`: mobile styles·alert HTML 회귀 테스트
## 검증 명령:
- `pytest tests/test_crm.py -q`
