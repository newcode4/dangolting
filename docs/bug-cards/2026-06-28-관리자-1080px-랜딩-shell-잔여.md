## 버그: PC 관리자 화면이 1080px로 중앙에만 표시됨
## 원인:
랜딩 iframe의 `injectShell()`이 parent `body`에 `dgt-landing` 클래스와 `#dgt-landing-shell-css`(max-width:1080px)를 주입. 관리자 URL로 이동해도 Streamlit SPA 특성상 body/head 잔여물이 제거되지 않음.
## 영향 파일:
- `assets/landing.css` (1080px shell)
- `utils/landing.py` (`injectShell`)
- `app.py`, `assets/theme.css`
## 수정 내용:
- admin 진입 시 `dgt-landing` 제거, `dgt-admin` 추가, `#dgt-landing-shell-css` 삭제
- `stAppViewBlockContainer` 포함 전체 너비 CSS + JS 강제
## 재발 방지:
- `test_admin_theme_strips_landing_shell`, `test_admin_desktop_full_width_layout`에 stAppViewBlockContainer·shell 제거 assert
