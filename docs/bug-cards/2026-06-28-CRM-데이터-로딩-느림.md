## 버그: CRM 기간 전환·첫 로그인 시 데이터 로딩이 느림
## 원인:
- 텔레그램 watch가 `get_sheet_dataframes()`보다 먼저 시트를 별도 조회(이중 fetch)
- CRM `st.tabs`가 선택 안 한 탭의 plotly까지 매 rerun마다 렌더
- 기간 radio 변경 시 전체 앱 rerun
- events JSONL·CRM snapshot 매번 재계산

## 영향 파일:
- `app.py`, `utils/sheets.py`, `utils/crm_ui.py`, `utils/telegram_notify.py`

## 수정 내용:
- 시트 1회 로드 후 텔레그램 boot watch에 `df` 전달
- `@st.cache_data`로 시트 values·데모 DataFrame 캐시 (`load_ver` 무효화)
- CRM 기간·서브탭을 `@st.fragment` + `st.radio` lazy render
- events·snapshot session 캐시 (`load_ver`, events mtime)
