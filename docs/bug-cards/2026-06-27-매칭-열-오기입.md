## 버그: 매칭 시 W열 TRUE · X 미체크 · Y에 날짜
## 원인:
- 폼에 T열(환불계좌) 등 추가 → U~Y 열 번호 +1 밀림
- 코드는 W=매칭여부, Y=매칭일로 쓰고 있었음
## 영향 파일:
- `utils/columns.py`, `docs/apps-script/Code.gs`
## 수정 내용:
- U=D-day, V=입금, W=매칭횟수, X=매칭여부, Y=환불, Z=매칭일
## 재발 방지:
- `tests/test_columns.py::test_col_positions_form_layout`
## 검증 명령:
python -m pytest tests/test_columns.py -q

## 시트 수동 정리 (테스트로 깨진 행):
- W: TRUE → 0 (숫자)
- X: 매칭됐으면 체크
- Y: 잘못 들어간 날짜 삭제
- Z: 매칭일 (선택)
