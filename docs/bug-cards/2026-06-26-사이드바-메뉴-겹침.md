## 버그: 왼쪽 ⋮ 메뉴 버튼이 겹쳐 보임 / 사이드바 안 보임
## 원인:
1. `collapsedControl` 등에 `position: fixed` 중복 적용 → ⋮ 겹침
2. 접기·열기 버튼을 모두 `display:none` → 사이드바 접힌 뒤 복구 불가
## 영향 파일:
- `assets/theme.css`
- `app.py` (`ensure_sidebar_visible`)
## 수정 내용:
- fixed 중복 스타일 제거
- 데스크톱: `aria-expanded="false"`일 때도 width/margin CSS로 사이드바 강제 표시
- 접힌 상태 자동 복구 JS (`ensure_sidebar_visible`)
- 모바일만 열기 버튼 표시
## 재발 방지:
- `tests/test_theme_css.py`
## 검증 명령:
```bash
python -m pytest tests/test_theme_css.py -q
streamlit run app.py
```
