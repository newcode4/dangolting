## 버그: 매칭 작업 목록에서 이름 클릭 시 CRM 탭으로 이동
## 원인:
- `st.tabs`는 rerun 시 항상 첫 번째 탭(CRM · 퍼널)으로 리셋됨
- 목록 행 클릭이 `toggle_select()` → `st.rerun()`을 호출해 탭이 초기화됨
## 영향 파일:
- `app.py`, `assets/theme.css`
## 수정 내용:
- 메인 탭을 `st.radio` + `session_state["admin_tab"]`로 교체해 rerun 후에도 현재 탭 유지
- 탭 순서: 매칭 작업 → 완료 목록 → 원본 데이터 → 설정 · 알림 → CRM · 퍼널
## 재발 방지:
- `tests/test_admin_tabs.py` — 탭 순서·st.tabs 미사용·admin_tab 키 계약
## 검증 명령:
- `python -m pytest tests/test_admin_tabs.py tests/ -q`
